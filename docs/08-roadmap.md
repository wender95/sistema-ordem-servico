# 8. Roadmap do Projeto

## 🎯 Fase 1: MVP Transacional (Escopo Atual)
- Especificação funcional e modelo de dados.
- Criação do banco de dados PostgreSQL/MySQL.
- Backend (API REST) para login, recebimento, despacho e encerramento.
- Frontend Web responsivo (interfaces enxutas para operadores e vendedores).
- Testes com massa de dados fictícios.

## 🚀 Fase 2: Evoluções Futuras (Pós-MVP)
- Conexão direta com ERP via API para importação automática do número da OS.
- Dashboards integrados em ferramentas de BI (Metabase / Power BI).
- Suporte a múltiplos executores simultâneos no setor de Frota.
- Registro de motivos padronizados para pausas operacionais longas.
