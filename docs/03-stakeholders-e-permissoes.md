# 3. Stakeholders e Níveis de Permissão

| Perfil | Quem inclui? | Permissões no OS Tracker |
| :--- | :--- | :--- |
| **Operacional** | Funcionários dos Setores (Criação, Impressão, Recorte, Preparação, Acabamento, Frota) | • Visualizar fila do **próprio setor** <br>• Receber OS na sua fila <br>• Despachar OS para o próximo setor permitido |
| **Vendedor** | Equipe Comercial / Vendas | • Criar novos fluxos para OS de qualquer número <br>• Consultar/Visualizar **todas as OS**<br>• Realizar a entrega final de OS ao cliente |
| **Diretoria** | Diretoria, Gerência, **Financeiro** e **RH** | • Consultar/Visualizar **todas as OS**<br>• Cancelar OS (com registro de motivo)<br>• Realizar a entrega final de OS<br>• Não realiza movimentação operacional interna (preserva auditabilidade) |
| **Administrador**| TI / Gestão do Sistema | • Gestão de usuários, setores e permissões<br>• Configuração da matriz de transição |
